Level × Stage Framework Matrix

Five analytical levels and four work stages. Each cell is a reusable strategy module.

Level DiagnoseFrame the problem AnalyzeFind facts PlanChoose position ExecuteDefine actions
🌐Macro Environment PEST Scan Scan political, economic, social, and technological shifts. PESTEL Analysis Add environmental and legal factors for a broader outside-in view. Scenario Planning Build future scenarios and test strategic choices under uncertainty. Trend Roadmap Turn key trends into time-based strategic actions.
⚔️Industry Competition Industry Issue Tree Break the industry question into a MECE issue structure. Five Forces / Ecosystem Assess industry pressure, profit potential, and ecosystem roles. Ecosystem Positioning Find the best position in the value chain. War Gaming Simulate competitor moves and counter-moves.
🏢Company Capability Company Issue Tree Structure the core operating issues at company level. SWOT / Financial Lens Combine strengths, weaknesses, opportunities, threats, and financial health. Strategy House ★ StratVault core module — from strategic intent to execution logic. 7S Alignment Use the 7S lens to align strategy, structure, systems, and people.
📊Business Unit SCQA Storyline Structure the business story through situation, complication, question, and answer. BCG Matrix Prioritize portfolio choices by growth and relative share. Ansoff / SPAN / FAN Evaluate growth options and resource allocation priorities. Product Roadmap Translate strategy into a product execution timeline.
🎯Execution Initiative Issue Tree Break initiatives into testable hypotheses and workstreams. Gap Analysis Quantify the gap between current state and target state. OKR / North Star Define measurable objectives, key results, and the North Star metric. Decode Table ★ StratVault core module — translate strategy into trackable quarterly actions.
