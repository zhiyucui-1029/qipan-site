# growth-breakthrough deck

这里放「增长问题破局 PPT」的可复用报告模板。

预期文件：

```text
deck.yaml   15 页顺序、输入输出契约、默认页面类型
slides/     每一种页面的结构模板
```

当前 v0.1 规格仍在 `项目规划/增长问题破局-deck-spec-v0.1.yaml`。等耐克中国样张跑通后，再把稳定版本迁到这里。

- `slides/cover.yaml`：封面页结构、输入字段、视觉要求和质检规则。

`项目规划/增长问题破局-deck-spec-v0.1.yaml` 仍作为探索稿保留。
