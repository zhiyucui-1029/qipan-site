# themes

这里放通用主题规则。

主题不是行业，也不是客户品牌。主题负责把颜色转成一套稳定的 PPT 视觉系统。

预期主题：

- `qipan-default`：qipan.site 默认深绿、深蓝、哑金风格
- `consulting-light`：浅底咨询报告风
- `consulting-dark`：深色封面和深色章节页
- `minimal-board`：更克制的棋盘推演风

当前已落地：

- `qipan-default.yaml`

每个主题都应该说明：

- 适合哪些报告
- 背景色规则
- 标题色规则
- 图表色规则
- 风险/机会/中性信号如何着色
- 用户品牌色如何被降饱和或增强对比度
