# slide-modules

这里放 artifact-tool 可编辑 PPTX 页面模块。

每个模块负责把 `slide_spec` 渲染成 PPT 原生对象。图片可以作为可替换 picture 插入，但标题、正文、模块文字、形状和图标不能烘焙进整页图片。

当前模块：

- `growth-breakthrough-cover/slide-01.mjs`：增长问题破局封面页。
- `growth-breakthrough-signal-evidence/slide-04.mjs`：公开信号扫描证据墙页。
- `industry-five-forces/slide-01..08.mjs`：行业五力分析工具包样张。
