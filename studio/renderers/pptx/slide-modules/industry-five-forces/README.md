# industry-five-forces

行业五力分析工具包 artifact-tool 模块。

目标：把波特五力从单页框架图拆成一套可编辑 PPTX：

1. 行业吸引力结论
2. 五力压力棋盘
3. 现有竞争者
4. 替代品威胁
5. 新进入者威胁
6. 上游议价力
7. 下游议价力
8. 利润驱动因子

## 常态化生成路径

默认数据是「中国运动鞋服行业 / Nike 中国参照」。后续换行业时，传入同结构 JSON 即可：

```bash
FIVE_FORCES_DATA_JSON='{"caseLabel":"某行业五力分析 · 2026","forces":[...]}'
```

## 图层约定

- 复杂视觉底座可以是 SVG / 图片资产，例如五力压力棋盘、渐变、暗纹、发光、压迫箭头和高质感卡片底纹。
- 标题、正文、分数、来源、证据数字和判断结论必须保留为 PPT 原生文本层。
- SVG / 图片资产只承接稳定视觉效果，不烘焙可变数据和判断文字。
- 不把整页烘焙成图片。
- 每页必须保留用户确认过的目标图，并用像素对比证明 PPT 截图和目标图对齐。
- 如果目标图含有文字和图标，必须先拆成「无字背景艺术层」和「可编辑文字/图标/形状层」，不能把整张目标图当底图。

## 混合式样张

当前第 2 页和第 3 页已切成混合式：

- `references/approved/slide-02-five-forces-pressure-board.png`：第 2 页已确认的完整视觉参考。
- `assets/slide-02-static-base.png`：第 2 页无文字、无图标、无压力箭头的静态艺术底板。
- `slide-02.mjs`：第 2 页的可编辑文字、Lucide 图标、动态压力箭头和图例。压力箭头根据 `score` 自动改变强度、透明度和颜色层级。
- `assets/force-detail-bg.svg`：第 3 页单项力量拆解视觉底座。

后续如果这两页审美通过，再把第 4-7 页的单项力量页复用第 3 页的混合式底座。

第 2 页支持局部压力覆盖，用于验证换行业后的箭头变化：

```bash
FIVE_FORCES_PRESSURE_MAP_JSON='{"rivalry":{"score":35},"supplier":{"score":76}}'
```

注意：正式模板通过标准不是“能导出 PPT”，而是截图接近 approved reference，同时标题、正文、分数、图标、箭头等关键元素仍可在 PPT 中独立选中或移除。

## 不允许

- 不允许直接跳到行动清单；最后一页应先落到利润驱动因子和后续验证议题。
- 不允许只有框架名称，没有证据和来源。
- 不允许为了可编辑性牺牲关键视觉质感；复杂视觉优先资产化。
