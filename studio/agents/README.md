# studio/agents

这里放 agent 角色说明和执行契约。

推荐角色：

- `orchestrator`：总导演，决定报告路线
- `industry-router`：识别行业，选择素材包
- `research`：收集事实，生成 source cards
- `strategy-board`：把事实映射到战略棋盘
- `deck-planner`：规划整套 PPT
- `visual-director`：选择视觉语言和生图 prompt
- `slide-builder`：按页面类型生成 slide spec
- `qa`：检查事实、文案、视觉和结构

这里不放具体报告输出。
